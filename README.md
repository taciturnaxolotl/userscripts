# Kieran's fancy userscripts

This is my personal collection of userscripts that do fun things to the web a wee bit more palatible :) If something is broken please open an issue or email me and I'll try to fix it!

The canonical repo for this is hosted on tangled over at [`https://tangled.org/dunkirk.sh/userscripts`](https://tangled.org/dunkirk.sh/userscripts)

## Install

Install a userscript manager like [Tampermonkey](https://www.tampermonkey.net/) and then click any of the following links:

- [Amazon URL Cleaner](https://tangled.org/dunkirk.sh/userscripts/raw/main/clean-amazon-urls.user.js)
- [Canvas Multi-File Upload](https://tangled.org/dunkirk.sh/userscripts/raw/main/canvas-multi-upload.user.js)
- [Claude Counter](https://tangled.org/dunkirk.sh/userscripts/raw/main/claude-counter.user.js)
- [Fast-forward merge for GitHub](https://tangled.org/dunkirk.sh/userscripts/raw/main/ff-for-github.user.js)
- [reMarkable Download & Print](https://tangled.org/dunkirk.sh/userscripts/raw/main/remarkable-download.user.js)
- [zyBooks auto play animations](https://tangled.org/dunkirk.sh/userscripts/raw/main/zybooks-autoplay.user.js)
